# FinResearch Pro

A professional-grade financial research platform built with Next.js 14, TypeScript, Tailwind CSS v4, and Recharts.

## Features

- **Dashboard** — Market overview, portfolio summary, sector performance
- **Stock Analysis** — Price charts with RSI, MACD, Bollinger Bands, SMA/EMA
- **Options Pricing** — Black-Scholes model, Greeks, options chain, payoff diagram
- **DCF Valuation** — Interactive DCF model with sensitivity analysis
- **Portfolio Analysis** — Efficient frontier, correlation matrix, Sharpe/Sortino metrics
- **Monte Carlo Simulation** — GBM stock price paths with confidence intervals
- **Macro Indicators** — Yield curve, CPI, GDP, Fed Funds rate
- **AI Analysis** — Simulated AI-driven investment analysis
- **Stock Screener** — Filter/sort stocks by fundamental metrics

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Tech Stack

- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS v4 (dark theme)
- **Charts**: Recharts
- **Font**: System font stack (Inter, system-ui)
- **Data**: All mock/simulated data — no external API keys required

## Build

```bash
npm run build
```
